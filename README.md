# 随记单词

手机浏览器里的手写英语本：扫描当前摄像头画面，校对识别结果，把单词、短语或例句做成卡片，再按间隔复习。

## 使用

1. 用 HTTPS 打开网站，允许摄像头权限。
2. 在“扫描”页打开摄像头，对准单词本后点“识别当前画面”。
3. 核对英文单词、短语、例句和释义，点“加入词库”。
4. 在“今日”页复习，翻卡后选“忘记了 / 有点模糊 / 记得很牢”。

扫描只从摄像头视频流读取一帧到内存中进行 OCR。网站不调用拍照保存接口，不会把扫描画面存入相册、词库或备份。单词和复习记录保存在当前浏览器的 localStorage。首次 OCR 需要联网下载 Tesseract.js 及英中识别模型，识别过程在本机运行。扫描会裁边、放大、增强对比度，并用常用英语词库纠正相近拼写；连笔或特别潦草的字仍请在加入词库前校对。

## 复习安排

新词立即进入待复习队列。选“忘记了”则 10 分钟后再复习；“有点模糊”通常次日复习；“记得很牢”会从 1 天、3 天逐步拉长间隔。它是一个简化的间隔复习算法，参考遗忘曲线的思路，并非精确预测个人记忆。

## 数据

设置页可导出 JSON 备份并导入。换浏览器、换手机或清除网站数据之前，请先导出备份。此版本没有账号或云同步。

## 部署到 GitHub Pages

这是零构建的静态网站。推送到仓库默认分支后，在仓库 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**，分支选择默认分支，目录选择 **/(root)**。GitHub Pages 提供 HTTPS，摄像头功能需要 HTTPS。

本地预览：

```sh
python3 -m http.server 8000
```

在电脑上打开 http://localhost:8000。手机测试摄像头请用已部署的 HTTPS 站点。
